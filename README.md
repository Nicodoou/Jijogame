# Jijogame — Rally procedural (Roblox)

Un jugador maneja por una ruta de rally infinita con un auto propio que se siente bien. Ver [requerimientos del MVP](docs/requerimientos-mvp.md).

## Cómo se trabaja

El proyecto lo programan dos agentes (A con Nico, B con Beni). Antes de cualquier tarea:

1. [docs/coordinacion-agentes.md](docs/coordinacion-agentes.md): áreas, flujo, issues, contratos, diario.
2. [docs/reglas-de-trabajo.md](docs/reglas-de-trabajo.md): subagentes, proceso de diseño, código, pruebas, bugs.
